# Adding the Capybara Icon to the VPN App

## Quick Guide

### Step 1: Save the Capybara Image

Save the capybara aviator image to the `macos-installer` directory:
```bash
# Save the image as:
macos-installer/capybara-icon.png
```

### Step 2: Create the macOS Icon

Run the icon creation script:
```bash
cd /Users/pasha/PycharmProjects/capybara/macos-installer
./create_icon.sh capybara-icon.png
```

**What this does:**
- Resizes the image to all required macOS icon sizes (16x16 to 1024x1024)
- Creates an `.icns` file (macOS icon format)
- Copies it to the app bundle Resources directory

### Step 3: Rebuild Installers

After the icon is created, rebuild installers:
```bash
# Rebuild all installers with the new icon
python3 build_all_installers.py --manifest
```

### Step 4: Verify Icon

The new installers will now include the capybara icon:
- In Finder, the app will show the capybara aviator
- In Spotlight search, the capybara icon appears
- In the Dock, when the app is running

## Manual Method (If Script Doesn't Work)

### Using Preview and Icon Composer

1. **Open the image in Preview:**
   ```bash
   open capybara-icon.png
   ```

2. **Resize to 1024x1024:**
   - Tools → Adjust Size
   - Width: 1024, Height: 1024
   - ✓ Scale proportionally
   - Save as `capybara-1024.png`

3. **Create iconset manually:**
   ```bash
   mkdir AppIcon.iconset

   # Generate sizes
   sips -z 16 16     capybara-1024.png --out AppIcon.iconset/icon_16x16.png
   sips -z 32 32     capybara-1024.png --out AppIcon.iconset/icon_16x16@2x.png
   sips -z 32 32     capybara-1024.png --out AppIcon.iconset/icon_32x32.png
   sips -z 64 64     capybara-1024.png --out AppIcon.iconset/icon_32x32@2x.png
   sips -z 128 128   capybara-1024.png --out AppIcon.iconset/icon_128x128.png
   sips -z 256 256   capybara-1024.png --out AppIcon.iconset/icon_128x128@2x.png
   sips -z 256 256   capybara-1024.png --out AppIcon.iconset/icon_256x256.png
   sips -z 512 512   capybara-1024.png --out AppIcon.iconset/icon_256x256@2x.png
   sips -z 512 512   capybara-1024.png --out AppIcon.iconset/icon_512x512.png
   sips -z 1024 1024 capybara-1024.png --out AppIcon.iconset/icon_512x512@2x.png

   # Convert to .icns
   iconutil -c icns AppIcon.iconset -o AppIcon.icns

   # Copy to app bundle
   cp AppIcon.icns payload/Applications/Capybara\ VPN.app/Contents/Resources/
   ```

4. **Rebuild installers:**
   ```bash
   python3 build_all_installers.py --manifest
   ```

## Troubleshooting

### Icon Not Showing After Installation

1. **Clear icon cache:**
   ```bash
   sudo rm -rf /Library/Caches/com.apple.iconservices.store
   sudo find /private/var/folders/ -name com.apple.iconservices -exec rm -rf {} \;
   killall Finder
   killall Dock
   ```

2. **Verify Info.plist references icon:**
   ```bash
   grep -A1 "CFBundleIconFile" \
     "payload/Applications/Capybara VPN.app/Contents/Info.plist"
   ```

   Should show:
   ```xml
   <key>CFBundleIconFile</key>
   <string>AppIcon</string>
   ```

3. **Check icon file permissions:**
   ```bash
   ls -l payload/Applications/Capybara\ VPN.app/Contents/Resources/AppIcon.icns
   # Should be readable: -rw-r--r--
   ```

### Icon Looks Blurry

- Ensure source image is at least 1024×1024 pixels
- Use PNG format with transparent background if possible
- The capybara image you provided should work great!

### Script Fails

If `create_icon.sh` fails:

1. **Check sips is available:**
   ```bash
   which sips
   # Should output: /usr/bin/sips
   ```

2. **Check iconutil is available:**
   ```bash
   which iconutil
   # Should output: /usr/bin/iconutil
   ```

3. **Manually verify image:**
   ```bash
   sips -g all capybara-icon.png
   ```
